# 🔑 核心概念定义

## 1. 真空区 (Vacuum Zone)
**定义**: 两个关键位之间无阻力的价格空白区间
**特征**: 进入后价格加速运动，阻力极小
**识别**: 关键位间距 ≥ 3%
**操作**:
- 进入真空区 → 快速跟进
- 真空区走完(距下一关键位<3%) → 止盈50%

## 2. 主力关键位密集区 (Dense Zone)
**定义**: 小价格区间(≤2%)内聚集3个以上关键位
**形成**: 数小时震荡，K线影线反复触及同一区域
**操作**:
- 密集区内 → 等待突破(SKIP)
- 突破密集区+1.5x放量 → 入场
- 假突破(<5分钟回落) → SKIP

## 3. 关键位识别标准
1. **前期高低点**: 7-30天内拐点价格
2. **K线影线聚集**: 1h/4h上下影线触及≥3次
3. **整数关口**: $100,000, $3,000等心理关口
4. **成交量放大区**: 历史成交量异常放大位置

## 4. 流动性时间窗口
| 时长 | 状态 | 操作 |
|-----|------|------|
| 0-4h | 💚充沛 | 持有 |
| 4-8h | 🟡警戒 | 注意止盈信号 |
| >8h | 🔴枯竭 | 强制平仓(妖币) |

**警戒信号**: 连续3根1h阴线 → 开始止盈

# 📊 分析模板

分析时按以下格式输出关键位信息:

```
【关键位分析】
- 上方阻力: $XXX (距离X%)
- 下方支撑: $XXX (距离X%)
- 密集区: $XXX-$XXX (是否形成: Y/N)
- 真空区: $XXX-$XXX (空间X%)

【当前位置】
- 在密集区内: 震荡观望
- 突破密集区: 趋势启动
- 在真空区内: 持仓/跟进
- 接近关键位(<3%): 准备止盈
```

# ⚠️ 核心规则

1. **没形成密集区不会走出趋势** - 必须等密集区形成
2. **真空区压力小，价格加速** - 突破后快速跟进
3. **流动性最多4-8h** - 超时必须止盈(妖币)
4. **假突破=无量回落** - 量<1.3x立即SKIP
5. **不在瀑布中间博反弹** - 等关键位确认
